# Security policy

## Reporting a vulnerability in Wroote Pro

Please do not open a public issue for a security problem.

Report vulnerabilities in the changes Wroote made (see `NOTICE`) privately to:
**security@wroote.eu**

Include the affected version or commit, a description, and steps to reproduce.
We acknowledge reports and coordinate disclosure with the reporter.

## Vulnerabilities in upstream Synapse

Most of the code in this repository comes from Synapse. If a problem also
exists in upstream Synapse, report it to Element under their policy:
https://element.io/security/security-disclosure-policy
(see also https://matrix.org/security-disclosure-policy/ for the Matrix
protocol and Matrix.org projects).

Wroote Pro follows upstream security releases and merges them into this fork.

## Supported versions

Only the latest release of Wroote Pro and the `main` branch receive security
fixes.
